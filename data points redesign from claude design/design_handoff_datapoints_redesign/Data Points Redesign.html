Data Points · layout exploration

Three directions for the manage screen. All use the existing token set — no new colours, no new fonts, no icon library. Each artboard shows the list state on top and the editor state below so you can compare them in one glance.

Variant A

Tracker cards · two-column grid

Each tracker becomes a card with a live mini-preview of its field. Hover-revealed actions remove visual noise. Editor opens as a drawer with a real-time preview pane on the right.

Inline expand · single-pane list

Why this works
  • The list is the editor — no modal switching, the page never "navigates away".
  • Each row carries a real preview of its field, so the type is obvious at a glance.
  • The locked-warning becomes a contextual pill on the row that needs it, instead of a yellow banner above the whole form.
  • Scales to many trackers without becoming a wall of grey rows.

Variant C

Settings-style · rail + detail pane

Trackers as a sidebar; selecting one opens an immersive detail panel with usage stats, edit fields, and a live diary-style preview. Closest analogue to settings panels in modern apps.

Trade-offs
  • Tracker becomes a "thing you visit", not a row you skim. More room for stats, history, presets.
  • Empty state of the detail pane is a natural home for the "+ new tracker" walkthrough.
  • Heavier UI for what is actually a small list — feels right at 5–20 trackers, less right at 2.
  • Doesn't squeeze well on phones; would collapse to a single-column drill-in on mobile.
